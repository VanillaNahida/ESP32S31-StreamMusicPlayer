# 内置封面像素清单 —— 交给 tools/icons/gen_photo.py 一次烘成 .bin
#
# 格式：源图路径  输出名  宽  高  格式(rgb565|rgb565a8|argb8888)
#
# 口径：
#   * 尺寸 = 显示尺寸（不要运行期缩放，那是每帧都要重算的）。
#   * rgb565   不带 alpha，用于完全不透明的图；
#     rgb565a8  保留 alpha，且比 argb8888 省 1/4 flash（黑胶唱片四周是透明的，用它）；
#     argb8888  只有在需要更高色彩还原时才用（比 rgb565a8 多 33% 体积）。
#   * 产物在 assets/cover/<输出名>_<宽>x<高>.bin，由各组件的 CMakeLists 用
#     target_add_binary_data(..., BINARY, RENAME_TO ...) 烘进 flash。
#   * ⚠ flash 很紧（app 槽 12.31 MB，见 partitions.csv），加图之前先看余量。
#   * ⚠ rgb565a8 是**平面分离**布局（先 w*h*2 的 RGB565，再 w*h 的 A8），
#     不是逐像素交错 —— 后者在真机上整块花屏（2026-11-24 修过）。
#
# 重新生成：
#   tools/font/venv/Scripts/python.exe tools/icons/gen_photo.py
