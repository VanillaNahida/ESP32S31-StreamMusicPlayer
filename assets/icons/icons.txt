# UI 位图图标清单 —— 交给 tools/icons/gen_icon.py --manifest 一次烘成
# components/ui_core/ui_icons.c（声明写在 components/ui_core/include/ui_icons.h）
#
# 格式：源图路径(相对仓库根)   C 符号名   输出边长(px)
#
# 尺寸口径：**按显示尺寸烘**。LVGL 运行期缩放是每帧都要重算的，图标这种固定
# 尺寸的东西没理由付那个代价（UI_HOME_ICON = 96 就是桌面图标块的边长）。
#
# ⚠ 源图不是标准 PNG 的先跑 tools/icons/prepare_sources.ps1：
#   assets/default.png 其实是 JPEG、assets/MomoIcon.png 其实是 ICO、
#   MomoTalk.html 里那个 ✕ 本来是内联 SVG。清单里只写转换后的 assets/icons/*.png。
#
# .svg 源**直接写在这里**即可：gen_icon.py 会用同目录的 svg_raster.py（纯标准库
# 的极简光栅化器）按 4 倍超采样渲染，再 box filter 缩到目标尺寸 —— 不需要
# cairosvg / PIL / Inkscape。SVG 一律按**白色**烘，运行时用
# lv_obj_set_style_image_recolor() 上色（状态栏就是这么做明暗与强调色的）。
#
# 核对生成结果（把烘好的位图另存成 PNG，拿图片查看器看一眼）：
#   tools/font/venv/Scripts/python.exe tools/icons/gen_icon.py \
#       --manifest assets/icons/icons.txt --preview build/icons_preview

# 标题栏的返回钮（ui_core.cc 的 ui_back_button_create）—— 边长与 UI_BACK_BTN_SIZE 对齐。
# 素材本身是"蓝色圆底 + 白色左箭头"的整块图标（106x102 RGBA，四角透明），
# 所以**整张烘进去**、按烘好的尺寸显示，不要再叠 lv_button 的圆底（会露出两层边）。
# ⚠ 尺寸沿革：36（太小）→ 72（用户要求翻倍）→ **64**（2026-10 用户要求"往左上角挪、
#   按钮中心与其他元素对齐"）：圆心要落在导航栏中线上，而栏高 UI_TITLEBAR_H(48) +
#   上下各一个 UI_PAGE_PAD(8) 正好 = 64 —— 上边贴着状态栏下沿、下边正好压到内容区
#   第一行，一像素都不越界（72 的话会顶进状态栏 4 px：状态栏是后画的半透明暗条，
#   会把圆顶切出一道平口）。
#   必须与 ui_metrics.h 的 UI_BACK_BTN_SIZE 一致，改一处就得改两处。
